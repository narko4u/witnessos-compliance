# Design Partner Onboarding Checklist

**Estimated timeline:** 2–4 weeks | **Questions:** partner-onboarding@witnessos.io

---

## Phase 1 — Legal & Setup (Days 1–3)

- [ ] Sign NDA and Design Partner Agreement
- [ ] Complete entity verification (W-9 / equivalent)
- [ ] Assign primary point of contact and backup
- [ ] Receive welcome packet — partner portal credentials and shared drive access

## Phase 2 — Technical Integration (Days 4–10)

- [ ] Review WitnessOS integration guide and API reference
- [ ] Provision test environment (sandbox tenant)
- [ ] Complete authentication setup (client credentials + webhook)
- [ ] Run end-to-end connection test — data ingestion confirmed
- [ ] Escalate any blockers to partner-eng@witnessos.io

## Phase 3 — Operational Review (Days 11–16)

- [ ] Schedule kickoff call — review workflow, reporting cadence, and SLAs
- [ ] Define alert thresholds and escalation paths
- [ ] Agree on weekly sync schedule and meeting invite sent
- [ ] Validate compliance with data retention and privacy policies

## Phase 4 — Evidence & Reporting (Days 17–21)

- [ ] Submit first sample report bundle (minimum 3 incidents)
- [ ] Review report output — verify signature chain and audit trail
- [ ] Complete user acceptance testing (UAT) sign-off
- [ ] Production go-live approved

---

**All items must be checked before production access is granted.**  
Need help? Contact us at **partner-onboarding@witnessos.io**.
